# Spore Rush

เกม CPE222 เขียนด้วย Verilog สำหรับบอร์ด **Digilent Nexys A7-100T** ใช้ Vivado 2024.2 และแสดงผล VGA 640×480 (4:3) ประมาณ 60 Hz

เริ่มจากฟักไข่แล้วเลือกสาย **Plant Eater** หรือ **Meat Eater** สายกินพืชมีโอกาสได้ DNA จากการชนหินให้แตกและเก็บได้ทันที สายกินเนื้อมีโอกาสได้จากการโค่นศัตรู เก็บ DNA ครบ 4 ชนิดเพื่อปลดล็อก Dash, More Damage, Poison และ Electric จากนั้นคัตซีนสั้นจะเปิดตัว **TOTO** บอสจะเตือนก่อนพุ่งและมีช่วงให้โจมตี เมื่อ HP เหลือครึ่งหนึ่งจะพุ่งถี่ขึ้น โค่น TOTO เพื่อชนะ

## เปิดโปรเจกต์

1. แตก ZIP หรือ clone repository จากนั้นเปิด [spore.xpr](spore.xpr) ด้วย Vivado 2024.2 ที่ติดตั้งอุปกรณ์ Artix-7 แล้ว
2. ตรวจว่า Top Module คือ **top_game** และรันที่ใช้งานคือ **synth_menu4x3** และ **impl_menu4x3** ถ้า IP แจ้งว่าขาด output products ให้เลือก **Generate Output Products** ในแท็บ **IP Sources**
3. กด **Generate Bitstream** ใน **Flow Navigator** แล้วรอจนสำเร็จ
4. ต่อบอร์ดผ่าน USB และต่อจอ VGA เปิด **Hardware Manager → Open Target → Auto Connect → Program Device** เลือก `spore.runs/impl_menu4x3/top_game.bit`

## ปุ่มบนบอร์ด

| ปุ่ม | การใช้งาน |
| --- | --- |
| BTNU / BTND / BTNL / BTNR | เลื่อนเมนู เลือกสาย หรือว่ายน้ำ |
| BTNC | ยืนยัน เคาะไข่ หรือเล่นใหม่จากหน้าผลเกม |
| SW0 / SW1 | เปิดหรือปิด Electric / Poison หลังปลดล็อก |
| SW2 | สับขึ้นเพื่อ Dash เมื่อพร้อม |
| SW3 | พักเกม |
| SW4 | กลับเมนูหลัก สับลงก่อนกด START |

หน้าเลือกสายเริ่มที่ Plant Eater เมนูไอคอนสกอร์บอร์ดแสดงคะแนนล่าสุดและคะแนนสูงสุดของการเปิดบอร์ดครั้งนั้น มุมขวาบนของเกมแสดงสถานะสกิล เมื่อเข้าใกล้ศัตรูจะเห็นชื่อและ HP ที่ด้านบนของจอ ส่วนมินิแมปจะแสดงตำแหน่งบอส

ตัวละครหันได้ 8 ทิศ กดสองแกนพร้อมกันเพื่อหันเฉียง เช่น BTNU + BTNR = NE (ขึ้นขวา) รองรับทั้งปุ่มบอร์ดและจอย UART ปล่อยปุ่มแล้วจำทิศล่าสุด ปุ่มตรงข้ามกันหักล้างในแต่ละแกน ภาพตัวละคร ชิ้นส่วน DNA และพื้นที่โจมตีด้านหน้าหันตามทิศเดียวกัน

## ตรวจและดูภาพโดยไม่มีบอร์ด

ดูวิธีรันใน [sim/README.md](sim/README.md) ชุดทดสอบใช้ Icarus Verilog จำลอง RTL จริงและอ่านภาพจาก ROM `.coe` ของโปรเจกต์ สร้างภาพ 8 ทิศและ GIF ว่ายน้ำไว้ใน `sim/output/` การจำลองนี้ยังไม่ยืนยันผล synthesis, routed timing หรือการทำงานบนบอร์ดของโค้ดที่แก้ล่าสุด

## โครงสร้างซอร์ส

ไฟล์ต่อไปนี้อยู่ใต้ `spore.srcs/sources_1/`

| ไฟล์หรือโฟลเดอร์ | หน้าที่ |
| --- | --- |
| `new/top_game.v` | เชื่อมปุ่ม จอย UART สถานะเกม กล้อง เมนู คัตซีน และ VGA |
| `imports/files/game_core.v` | คุมคะแนน HP การเติบโตและเงื่อนไขแพ้ชนะ |
| `imports/FSM/` | FSM ของรอบเกม วิวัฒนาการ Dash ศัตรู และบอส |
| `new/ecosystem_ai_and_collision.v` | หิน ศัตรู การชน การดรอป DNA และการต่อสู้กับบอส |
| `new/sprite_renderer.v` | ฉาก ตัวละคร วงน้ำ ชื่อบอสระหว่างคัตซีน ออร่า มินิแมปและ HUD |
| `imports/menu_screens/` | หน้าเมนู ภาพเลือกสาย หน้าผลเกม ป้ายศัตรู และข้อมูลภาพ `.mem` |
| `imports/rom_data/` และ `ip/` | ข้อมูล `.coe` สำหรับแผนที่ tile และ sprite กับคอนฟิก IP ของ Vivado |
| `new/vga_controller.v` และ `new/peripherals_driver.v` | จังหวะ VGA, LED และ 7-segment |

ขาบอร์ดกำหนดใน `spore.srcs/constrs_1/new/nexys_a7.xdc` คอนฟิก IP ใช้พาธสัมพัทธ์ไปที่ไฟล์ภาพในโปรเจกต์ เมื่อแก้ข้อมูล ROM ให้เก็บไฟล์ `.coe` และ `.xci` ที่ใช้คู่กันไว้ใน repository ด้วย ส่วนไฟล์ `.bit` และโฟลเดอร์ผลบิลด์ให้ Vivado สร้างได้จากซอร์ส

ซอร์สต้นทางรุ่นคัตซีนสร้าง bitstream สำเร็จใน Vivado และรายงาน routed timing ผ่าน ส่วนโปรเจกต์ใน ZIP ได้ตรวจพาธซอร์สและไฟล์ ROM หลังย้ายแล้ว การ build จาก ZIP และการลองเล่นบนบอร์ดยังไม่ได้ทดสอบ
